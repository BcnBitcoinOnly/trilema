Datele sunt proaspete, de-acum cinci minute si acopera luna Septembrie curent. Zic sa nu panicati, zece milioane de hituri nu-i chiar asa de imens de mult in zece zile.

Si-acum, uimirile. Frumos, pe liniute :

  • Mai exista Windows 3.xx. Oare o fi 3.1 sau 3.11, pe bune acuma ? Oare ruleaza pe 386 sau pe 486 ? In Kenya sau unde ?
  • Mai exista Windows ME. Cineva, undeva ruleaza Windows ME. Aparent sunt citit chiar si-n Iad.
  • Nici macar nu-mi amintesc care-o fost Windows 2003 ?
  • Apropo de BSD : OpenBSD 0 % ; NetBSD 0 % ; FreeBSD 0 %. Cred c-am spus tot.
  • Ce este VectorLinux ?
  • Ubuntu 0.3%. Admitind ca nu-s singurul care ruleaza Ubuntu rezulta ca absolut nu contez la mine pe site. Nasol moment.
  • Suse 0 % ; Red Hat 0 % ; Mandriva (or Mandrake) 0 % ; Gentoo 0 % ; Fedora 0 % ; Debian 0 % ; Centos 0 %. Cred ca suntem edificati cu "cine va cistiga razboiul linux".
  • Nintendo Wii 3,145. Daca asta nu-i hacker chiar n-am idee cine poate pretinde c-ar fi. Mai lipseste sa vad acolo "Prajitor de piine" in lista si e completa, ca pe NES nu cred ca se baga nimeni.
  • Sun Solaris 41. I win the Internets. Definitively.
  • AmigaOS a cerut o pagina pe 3 Septembrie. De-atunci o tot primeste. A procesat pina azi doua elemente : un <div> si-un <span>. Avem mari sperante pentru anul curent.
  • Commodore 64. PE BUNE ACUMA!!!
  • HP UX. HP UX! Cu care ocazie am cistigat restul de Interneti, neramasi de la faza cu Solaris.

Ce-ar mai fi de spus ?
