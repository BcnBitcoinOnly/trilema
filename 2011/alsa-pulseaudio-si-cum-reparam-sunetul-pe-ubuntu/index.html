ALSA, PulseAudio si cum reparam sunetul pe Ubuntu

Monday, 07 November, Year 3 d.Tr. | Author: Mircea Popescu

Aveti probleme cu sunetul in Ubuntu ? Si lista e chiar prelunga, de la chestii banale gen "nu merge, e tot mut ca o lebada" la chestii subtile, pentru experti, gen "in Opera pe youtube in html5 sunetul blocheaza uneori browserul complet si irecuperabil, 100% CPU si nu-si mai revine, tre' omorit sa nu se mai chinuie, da' un $ sudo alsa restart aplicat inainte de-a porni un video dar dupa ce ati facut selectia de html5 previne problema".

Chestia-i cam asa : PulseAudio e un cacat ingrozitor si indescriptibil. ALSA e un pachet acceptabil scris (in special pentru ca nu prea are alternative, plus ca-i inradacinat adinc de tot prin kernel deci nu-i practic sa-l dezinstalati). Cele doua interactioneaza de asa natura incit pare, pentru un utilizator rational, ca ALSA e problema. Aceasta aparenta este falsa. PulseAudio e de fapt problema.

Asa ca solutia e in doi pasi : mergeti pina-n synaptic, cautati orice-i cu pulseaudio si dezinstalati. Tot. Chestie care va va bulibasi complet instalarea de ALSA, bineinteles, in dulcele stil clasic al imbecilitatii pe linux. Da' nu-i problema, ca cine poate sa strice poate si repara. In trei pasi simpli :

1. Mergeti pina la aici si notati ce scrie acolo la versiunea curenta a :

  • Driver (alsa-driver). Description : Kernel drivers ;
  • Library (alsa-lib). Description : Userspace library ;
  • Utilities (alsa-utils). Description : Utilities aplay,arecord,amixer etc.

2. Dupa care aveti aici un mic script, editati in el versiunile corecte :

#!/bin/sh
# ---- Aici intra versiunile scoase la pct. 1 ----
DRV=1.0.24
LIBV=1.0.24.1
UTILV=1.0.24.2
# ---- Aici intra versiunile scoase la pct. 1 ----

# Belim pula
pula() { echo "S-o belit, frate." exit}

# Oprim ALSA
sudo /etc/init.d/alsa-utils stop

# Sulele suleleee
sudo apt-get -y install build-essential ncurses-dev gettext xmlto libasound2-dev
sudo apt-get -y install linux-headers-`uname -r` libncursesw5-dev

if [ $? -ne 0 ]; then pula fi

# Muie Pulse. Am mai zis ?
rm -rf ~/alsa* ~/.pulse*

# Foldere
sudo rm -rf /usr/src/alsa
sudo mkdir -p /usr/src/alsa
cd /usr/src/alsa

if [ $? -ne 0 ]; then pula fi

# Download
sudo wget ftp://ftp.alsa-project.org/pub/driver/alsa-driver-$DRV.tar.bz2
sudo wget ftp://ftp.alsa-project.org/pub/lib/alsa-lib-$LIBV.tar.bz2
sudo wget ftp://ftp.alsa-project.org/pub/utils/alsa-utils-$UTILV.tar.bz2

if [ $? -ne 0 ]; then pula fi

# Unpack
sudo tar xjf alsa-driver*
sudo tar xjf alsa-lib*
sudo tar xjf alsa-utils*

if [ $? -ne 0 ]; then pula fi

# Setup
cd alsa-driver*
sudo ./configure
sudo make
sudo make install

if [ $? -ne 0 ]; then pula fi

# Setup Lib
cd ../alsa-lib*
sudo ./configure
sudo make
sudo make install

if [ $? -ne 0 ]; then pula fi

# Setup Utils
cd ../alsa-utils*
sudo ./configure
if [ $? -ne 0 ]; then
sudo ln -s libpanelw.so.5 /usr/lib/libpanelw.so
sudo ln -s libformw.so.5 /usr/lib/libformw.so
sudo ln -s libmenuw.so.5 /usr/lib/libmenuw.so
sudo ln -s libncursesw.so.5 /lib/libncursesw.so
sudo ./configure
fi
sudo make
sudo make install

if [ $? -ne 0 ]; then pula fi

echo -e "\nRestart, run \"sudo alsaconf\" si pe urma iara restart. Pentru ca Ubuntu e Windows pentru tocilari."

# COMPLETE

Mai departe:

  1. pasul 3.1 : salvati chestia aia ca fisier, sa-i zicem alsa-update.sh
  2. pasul 3.2 : $ chmod +x alsa-update.sh ca adica sa-i dea permisiune de executie
  3. pasul 3.3 : $ ./alsa-update.sh ca sa-l rulati.

Si cu asta gata, ati scapat (definitiv, sper eu) de PulseAudio si v-ati si adus la zi driverele de ALSA. Ca-n filme. Si anume, ca-n filmele cu prosti.
